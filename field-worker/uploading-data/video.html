Video

Videos can be uploaded to the raw directory of collections for storage as well as for further processing into derived products.

Requirements​

  • IDM administrators configure sensors for the formats allowed to be used. A video format must be selected as one of those sensor options. You can view the enabled formats in the sensor definition by clicking the sensor name in the top of the collection and referencing the Formats Captured With This Sensor section.
  • Only one video can be uploaded per upload.

All files uploaded to the raw tab of a collection must be compressed into a .zip or .tar.gz file.

IDM checks each file in the archive when the upload finishes. The results are shown on the upload's task on the Workflow Tasks page.

  • Folders: files inside folders in the archive are uploaded, but the folders are not kept. All files are placed directly in the raw tab.
  • File names: only letters, numbers, periods (.) and underscores (_) are kept. Any other character, including spaces and hyphens (-), is replaced with an underscore. For example, IMG 001-a.jpg is stored as IMG_001_a.jpg.
  • Duplicate names: if two files end up with the same name, because they were in different folders or because of replaced characters, only the first one is kept. The others are skipped with an error message.
  • Unsupported file types: files that don't match the collection's format are skipped with an error message. See Supported File Formats. If no files in the archive are supported, the whole upload fails.
info

To avoid skipped files, give every file a unique name that uses only letters, numbers, periods and underscores. For example, video_name.mp4 is a valid file name.

Prerequisites​

  1. Create a collection if one doesn’t exist.
  2. Set the sensor format to a video format for the collection.

Upload Video (radiometric or non-radiometric)​

  1. Select the upload button from the collection modal you want to upload a video to. A new upload modal will load on the screen.

  2. Drag & drop your compressed (.zip) file onto the “Drag & drop” area at the bottom of the form – or – click “Select file” to select your compressed (.zip) from the file system.

  3. Select Upload to start the process.

info

OPTIONAL: Once your video is uploaded you can navigate to the video tab of your collection to see all uploaded videos and preview them as needed.

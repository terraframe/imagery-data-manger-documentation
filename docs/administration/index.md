Administration of the IDM system must be done by users with the Administrator role. Administrators can do all the functions of a Field Worker (see the [Field Worker Guides](../field-worker/index.md)) but also have the ability to administer the configuration of the IDM system.

Administration pages are opened from the navigation menu in the upper right hand corner of IDM. Administrators see four extra items at the bottom of the menu: *UAV*, *Equipment*, *System Configuration* and *System Info*.

## UAV

- [UAV Registration](uav-registration.md): register the UAVs used to collect data.

## Equipment

- [Platforms and Sensors](platforms-and-sensors.md): register the platforms and sensors used to collect data, and the types, manufacturers and wave lengths they are built from.

## System Configuration

The System Configuration page has a section for each of these, from top to bottom:

- [Accounts](accounts.md) (*Manage Accounts*): add, bulk upload, and edit users and their roles.
- [Icons](icons.md) (*Manage System Images*): change the IDM logo.
- [Email Settings](email-settings.md) (*System Email*): configure the email server used for notifications.
- [Session Event Log](session-event-log.md): monitor user sign-ins.
- [Organizations](organizations.md) (*Organizations* and *Organization Integrations*): synchronize the organizations users and data belong to.
- [Custom Hierarchies](custom-hierarchies.md) (*GeoPrism Registry Integrations*): import geographic hierarchies for filtering sites in the Site Viewer.

## System Info

- [System Info](system-info.md): see the IDM and Open Drone Map versions that are running, and the release notes.

## Other Administration Tasks

- [Help Pages](help-pages.md): write the organization-specific help pages users see when they click *Need some help?*.
- [Reporting](reporting.md): collection and processing quality reports, from the *Report* menu item. The collection report is available to all users; the processing quality report is only available to Administrators.
- [Public Image Services](public-image-services.md): access published products as Cloud Optimized GeoTIFFs.
